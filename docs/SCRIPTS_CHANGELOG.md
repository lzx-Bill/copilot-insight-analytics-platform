## 🎯 功能特性

### 端口检查
- 在启动前检查所有必需端口
- 显示占用端口的进程信息
- 提供确认选项继续或取消

### 智能启动
- 自动检测 Docker 是否运行
- 等待容器健康检查通过
- 验证服务成功启动
- 显示访问地址

### 优雅停止
- 先尝试优雅关闭窗口
- 超时后强制终止进程
- 查找所有相关进程（防止遗漏）
- 可选保留 Docker 容器

### 状态监控
- 实时显示所有服务状态
- Docker 容器健康状态
- HTTP 服务可访问性检查
- 资源使用情况（CPU、内存）

## 📊 使用统计

### 启动流程
```
检查端口 → 启动 Docker → 等待健康 → 启动后端 → 启动前端 → 完成
   ↓           ↓           ↓            ↓           ↓          ↓
  2秒         3秒         30秒         30秒        60秒       总计
```

总耗时：约 2-3 分钟（首次启动可能需要更长时间）

### 停止流程
```
查找进程 → 停止前端 → 停止后端 → 停止 Docker → 完成
   ↓          ↓          ↓           ↓          ↓
  1秒        3秒        3秒         5秒        总计
```

总耗时：约 10-15 秒
